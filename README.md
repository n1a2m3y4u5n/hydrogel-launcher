# hydrogel-launcher

알긴산 바이오 하이드로겔로 산불 초기 진압을 노리는, 아두이노 기반 계량·혼합·발사 장치입니다.

- 수상: 제15회 에너지·환경 탐구대회 우수상 ((사)환경교육센터 이사장상)

## 소개

알긴산 용액과 염화칼슘(CaCl2) 용액을 1:1 부피로 섞으면 하이드로겔이 만들어집니다. 이 장치는 두 용액을 펌프로 보내 유량계로 양을 재고, 합류시켜 저장 탱크에 모은 뒤 앞쪽 펌프로 발사합니다. 아두이노가 릴레이로 펌프를 제어하고, 시리얼 명령으로 조작합니다.

## 주요 기능

- 두 탱크의 용액을 각각 펌프와 유량계(펄스 방식)로 계량하고 Y자로 합류시켜 저장 탱크에 채웁니다.
- 앞쪽 펌프로 저장 탱크의 용액을 발사합니다.
- 시리얼 명령: `fill`, `stopfill`, `fire`, `stopfire`, `stop`, `status`, `vol X`, `test` (v7은 `ratio` 추가)
- v6은 좌우 누적 부피 비율로 1:1을 맞추는 피드백 제어를 넣었습니다. v7은 한쪽 유량계가 펄스를 못 읽을 때 한쪽 펌프만 꺼지는 문제를 막으려고 비율 제어를 기본 꺼짐으로 두고, 유량계 정지를 감지하면 양쪽 펌프를 계속 켭니다.
- 릴레이는 액티브 LOW로 설정되어 있고, `RELAY_ACTIVE_HIGH` 상수로 바꿉니다. `test` 명령으로 극성을 확인합니다.

## 기술

- Arduino 스케치(C++), 핀 인터럽트로 유량계 펄스 계수
- 릴레이 모듈로 펌프 3개 제어 (왼쪽 4번, 오른쪽 5번, 발사 6번 핀), 유량계는 3번·2번 핀
- 주석에 적힌 실험 조건: 알긴산 나트륨 1.0 wt% + 피트산 0.5 wt%, CaCl2 2.0 wt%, 부피비 1:1

## 파일

| 파일 | 설명 |
|---|---|
| `hydrogel_launcher_v5_relay.ino` | 릴레이 버전 첫 안 |
| `hydrogel_launcher_v6.ino` | 1:1 비율 피드백 제어 추가 |
| `hydrogel_launcher_v7.ino` | 한쪽만 분사되는 문제 대응 (비율 제어 기본 꺼짐, 유량계 정지 감지) |
| `hydrogel_launcher_v7_1.ino` | 서보 모터와 컬러 센서(TCS3200 계열 핀 구성) 시험용 스케치. 펌프 제어는 없음 |

## 실행 방법

1. Arduino IDE에서 `.ino` 파일을 엽니다 (펌프 제어는 `hydrogel_launcher_v7.ino` 권장).
2. 보드와 포트를 선택해 업로드합니다.
3. 시리얼 모니터를 열고 `test`로 릴레이 극성을 먼저 확인합니다 (펌프 부하를 뗀 상태에서).
4. `fill`로 채우고 `fire`로 발사하며, `stop`으로 모두 멈춥니다.

보드 종류는 코드에 적혀 있지 않습니다. 인터럽트 핀(2, 3번)과 `Servo.h` 사용으로 보아 Uno 계열로 보입니다.
